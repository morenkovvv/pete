# 🏆 Final Quest

> **Длительность:** 40–50 минут. ⏳
> Повторяем ВСЁ: **To Be**, **Present Simple**, **Past Simple**, **irregular verbs**, **эмоции**, **семья**, **тело**.

## 🧠 Правило: «Ты — герой квеста»

Пит, ты прошёл долгий путь! 🚀 Как в игре, теперь у тебя есть «навыки»:
- Ты умеешь говорить, **кто ты** (To Be)
- Ты умеешь говорить, **что ты делаешь** (Present Simple)
- Ты умеешь говорить, **что было вчера** (Past Simple)
- Ты знаешь **сильные слова** (неправильные глаголы)
- Ты умеешь **чувствовать** (эмоции)
- Ты знаешь **свою семью** и **тело**

Теперь — финальный босс! 🐉 Ты победишь его, если вспомнишь всё разом.

## 📝 Банк слов для квеста

| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| To Be     | <span lang="en-US">am</span> (был), <span lang="en-US">is</span> (есть), <span lang="en-US">are</span> (есть), <span lang="en-US">was</span> (был), <span lang="en-US">were</span> (были) |
| Действия  | <span lang="en-US">play, run, jump, eat, drink, read</span>                                                                                                                               |

| Эмоции    | <span lang="en-US">happy, sad, angry, surprised, tired</span>                                                                                                                             |
| Семья     | <span lang="en-US">mom, dad, brother, sister, grandma, grandpa</span>                                                                                                                     |
| Тело      | <span lang="en-US">head, eyes, nose, hands, legs, heart</span>                                                                                                                            |

## 🎮 Game Time — «Финальный босс» 🐉

### 🎯 Задание 1: «Тёплый старт»

Найди пару (соедини линией):

I am      счастлив
I was     вчера
I love    семью
I played  в футбол

### 🧩 Задание 2: «Космическая гонка»

Скажи вслух как можно быстрее:
1. Назови **3 члена семьи** по-английски.
2. Назови **3 части тела** по-английски.
3. Назови **3 эмоции** по-английски.
4. Скажи: «Вчера я **играл**» по-английски.
5. Скажи: «Я **люблю** свою семью» по-английски.
