Урок: **Programming & AI** — разговаривай с машинами! 💻🤖

Знаешь, на каком языке «думают» компьютеры, умные дома, роботы и искусственный интеллект? — На **английском**. 🗣️💻

Все команды, коды и даже то, как ты говоришь с «умными» помощниками — всё это по-английски. Хочешь создавать игры, сайты и роботов? Тогда этот урок для тебя! 🚀

---

🕵️‍♂️ Главное правило: «Код — это английский в чистом виде»

Программисты пишут команды по-английски. Даже если учишь «программирование» в школе — слова всё равно английские. Так что, зная английский, ты уже наполовину программист! 😎

| Слово | Перевод | Пример | Эмодзи |
| ------ | ------- | ------ | ------ |
| **code** | код / программа | I write code. — Я пишу код. | 💻 |
| **program** | программа | A computer program. — Компьютерная программа. | 📜 |
| **bug** | ошибка (жучок) | There is a bug. — Здесь ошибка. | 🐛 |
| **debug** | исправлять ошибки | I debug my code. — Я исправляю ошибки в коде. | 🔧 |
| **command** | команда | Run the command. — Выполни команду. | ⌨️ |
| **data** | данные | Big data. — Большие данные. | 📊 |
| **prompt** | запрос (для ИИ) | Write a prompt. — Напиши запрос. | ✍️ |
| **AI (artificial intelligence)** | искусственный интеллект | AI can help. — ИИ может помочь. | 🤖 |

> 💡 **Secret:** сейчас любой человек может «разговаривать» с ИИ на английском — и получать ответы. Это как иметь суперпомощника. А чтобы использовать его на полную, нужен английский. 🤖✨

Представь, что ты разговариваешь с роботом-помощником. Закончи фразы:

1. Hello! Can you **help** me? — Привет! Ты можешь помочь мне?
2. Please **write** a story about a dragon. — Пожалуйста, напиши историю про дракона.
3. I like **games**. What is your favorite game? — Я люблю игры. Какая твоя любимая игра?

Произнеси это вслух — ты только что «поговорил» с ИИ по-английски! 🎉
